# 📊 HR Analytics Dashboard (Power BI)

## 🔍 Overview
This project presents a comprehensive **HR Analytics Dashboard** built using **Power BI**. The dashboard provides meaningful insights into employee data, helping organizations make informed HR decisions.

It covers key HR metrics such as **headcount, attrition, promotions, performance, and employee demographics**.
